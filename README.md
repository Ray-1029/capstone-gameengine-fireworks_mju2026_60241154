# 등롱 아래 불꽃놀이 — Unity 프로젝트

## 현재 버전: 좌우 배치와 자연스러운 불씨

현재 공연은 **163개 큐 / 13종 프리팹**입니다. 기존 130개 큐의 기준 시각·상승 시간·발사/폭발 기준과 음악 파일은 보존하고, 불꽃 위치를 16:9 화면의 양옆까지 분산했습니다. 가장 큰 국화는 기둥 오른쪽의 열린 하늘 안에 유지합니다. Game 뷰를 **16:9**로 두면 의도한 기본 구도로 볼 수 있습니다.

작은 음악 구절에는 크기와 밝기를 낮춘 **21개** 보조 큐, 강한 구절의 바깥쪽 하늘에는 **12개** 악센트를 추가했습니다. 추가 큐도 원본 음원에서 측정한 어택에 맞추었으며, 측정된 짧은 무음과 첫 대형 폭발 직전의 쉼은 유지했습니다. 작은 큐의 밝기는 0.48–0.65, 크기는 0.42–0.70로 제한했습니다.

별과 기울어진 고리는 불씨마다 발화·소멸 시각, 속도, 저항을 달리했습니다. 밝은 불씨 끝과 짧게 끊기는 꼬리가 반짝이고 중력에 따라 내려오므로, 모양이 완벽한 선으로 고정되지 않습니다.

추가한 네 프리팹은 `Assets/Festival/Prefabs/`에 있습니다.

| 프리팹 | 연출 |
|---|---|
| `Gold_Palm.prefab` | 굵은 가지 몇 줄이 위로 퍼졌다가 휘는 금빛 야자수형 |
| `Red_Gold_Peony.prefab` | 짧은 꼬리의 붉은 둥근 꽃과 안쪽 금색 꽃심 |
| `Gold_Crossette.prefab` | 날아간 불씨가 각각 네 갈래로 갈라지는 크로세트 |
| `Gold_FallingLeaves.prefab` | 천천히 흩날리며 반짝이는 금빛 낙엽 |

**카메라:** Play → Game 화면 클릭 → **우클릭을 누른 채 드래그**. 방향키로도 회전하고 휠로 확대·축소합니다. **C / Home**은 기본 구도 복귀, **F1** 또는 화면 오른쪽 위 **Camera / Help**는 조작 안내입니다. Space는 일시정지/재개, R은 처음부터 재생합니다. 카메라 위치는 관객 자리에 고정되어 있고 시선과 화각을 조작합니다.

편집은 `Assets/Festival/Data/ShowTimeline.asset`에서 합니다. 큐별 `Brightness`도 추가했습니다. `CALM`은 잔잔한 보조 큐, `WIDE`는 좌우 악센트입니다. 결과와 렌더는 `Verification/Wide/`, 수정 전 전체 백업은 `Verification/BeforeWide/`입니다. 씬 경로는 `Assets/Festival/Scenes/LanternFestival.unity`입니다.

직접 비교할 구간: **18.9–20초** 좌우 빨강의 응답, **53–64초** 작은 보조 불꽃과 대형 전의 쉼, **73–77초** 좌우 확장, **126–139초** 잔잔한 보조 큐, **155–170초** 큰 반복과의 대비입니다. `Analysis/all-cues.csv`에는 현재 163개 큐의 발사·폭발 시각이 있습니다.

**현재 버전 검증:** 13종의 프레임 이력과 무관한 파티클 계산, 카메라 회전·줌 제한·복귀, 163개 큐 참조, 대형 국화의 화면 경계, 실제 무음 구간에 신규 발사/섬광이 없는지를 통과했습니다. 기본 16:9 구도의 바깥쪽 폭발 중심은 왼쪽 27개, 오른쪽 51개입니다. 130.10초의 잔잔한 화면은 160.60초 하이라이트의 약 28.6% 수준의 추가 픽셀 밝기를 보였습니다. 이는 두 렌더에서 동일 배경을 뺀 비교이며 곡 전체의 밝기 비율을 뜻하지 않습니다.

실제 속도로 **189.640초 전곡과 잔광**을 재생하고 250 ms 처리 지연, 재시작, 일시정지와 재개까지 확인했습니다. 공연 검사는 **오류 0건**, 14,921회 관측에서 음원 샘플 시계와 DSP 기준 시계의 최대 차이는 **21.333 ms**였습니다. 런타임 코드와 프리팹·큐 데이터는 이 검증본과 동일합니다. 실제 마우스·키 입력을 직접 조작한 GUI 검사는 하지 못했습니다. 배치 에디터의 Unity Search 초기화 예외가 1회 있었으며 공연 검사는 이후 끝까지 완료됐습니다.

- `Verification/Wide/playback-validation.txt`: 전곡, 지연 복구, 재시작·일시정지 결과.
- `Verification/Wide/scene-validation.txt`, `wide-validation.txt`, `shapes-camera-validation.txt`: 배치·참조·13종·카메라 검사.
- `Verification/Wide/data-regression.json`: 기존 130개 타이밍과 음악 보존, 추가 33개의 실제 측정 어택 사용, 좌우 분포·밝기 비교.
- `Verification/Wide/05_early_sides.png`, `01_wide_phrase.png`, `02_quiet.png`, `03_highlight.png`, `04_final.png`: 실제 Unity Camera 렌더.

Unity가 열려 있다면 창으로 돌아가 파일 가져오기와 컴파일이 끝난 뒤 Play를 누르세요. 수정은 현재 씬이 참조하는 타임라인과 프리팹에 저장되어 있으므로 새 씬으로 갈아탈 필요가 없습니다. 제작용 `Festival > Apply wide and natural fireworks revision`은 배치·프리팹을 다시 설정하는 메뉴이므로 이후 수동 편집 후에는 사용하지 마세요.

## 이전 퍼레이드 확장 기록

주요 불꽃의 펼쳐지는 폭은 약 1.5–1.6배, 국화·버드나무·빨강 불꽃의 입자 수는 약 1.5배로 키웠습니다. 기존 92개 큐에 측정된 음원 어택을 사용하는 38개 큐를 더해 **130개 큐 / 9종 프리팹**으로 확장했습니다. 배경 오브젝트와 음악 파일은 그대로 사용하며, 기본 카메라는 커진 불꽃에 맞춰 조금 더 위를 봅니다.

새 프리팹은 `Assets/Festival/Prefabs/`에 있습니다.

| 새 프리팹 | 연출 |
|---|---|
| `Gold_Star.prefab` | 다섯 꼭짓점의 금색 별. 실제 3D 공간에 얇은 별 모양으로 입자를 배치합니다. |
| `Gold_Red_MultiBreak.prefab` | 12개 불씨가 흩어진 뒤 각각의 위치에서 작은 금색·빨강 불꽃이 한 번 더 터집니다. |
| `Gold_Strobe.prefab` | 약 1.25초 동안 짧게 반짝이는 금빛 불꽃. |
| `Gold_Red_DoubleRing.prefab` | 기울기가 서로 다른 금색·빨강 고리 두 개. |

다중 폭발의 2차 섬광은 첫 폭발 뒤 **1.15–1.54초**에 시작하며, 음악의 새 강세를 따로 지정한 큐가 아니라 첫 큐에 딸린 상대 연출 시각입니다. Inspector의 `Secondary Delay`, `Satellite Count`, `Secondary Color`로 조정할 수 있습니다. 반짝임의 빈도는 `Glitter Frequency`에서 바꿉니다.

**재생 중 카메라 조작**

- Game 뷰에서 **우클릭을 누른 채 마우스 이동** 또는 **방향키**: 관객의 위치에서 시선 회전.
- **마우스 휠**: 확대·축소.
- **C / Home**: 기본 구도와 화각으로 복귀.
- **우클릭 놓기 / Esc**: 커서 잠금 해제. 창 포커스를 잃어도 잠금이 풀립니다.
- **R**: 공연 재시작. **Space**: 음악·불꽃 일시정지/재개. **H**: 재생 상태 표시. **F1**: 카메라 조작 안내.

`Main Camera > Festival Look Camera`에서 감도, 회전 범위와 화각 범위를 바꿀 수 있습니다. 음악을 멈춰 놓고 카메라만 돌려볼 수도 있습니다. 카메라를 돌려도 음악과 불꽃 시각은 바뀌지 않습니다.

확장판의 실제 큐는 `Assets/Festival/Data/ShowTimeline.asset`, 전체 표는 `Analysis/all-cues.csv`에 있습니다. 확장판 렌더와 검사 결과는 `Verification/Parade/`에 저장됩니다. 이전 결과는 `Verification/BeforeParade/` 및 `LanternFestival_BeforeParade.unity`, `ShowTimeline_BeforeParade.asset`에 보관했습니다.

**확장판 검증:** Unity 컴파일, 9종 파티클 렌더, 12개 불씨의 2차 폭발, 카메라 회전·줌 범위·기본 구도 복귀, 전체 189.640초와 잔광 재생, 250 ms 프레임 지연 후 복구, 재시작, 일시정지·재개를 통과했습니다. 전곡의 57,723회 시계 관측에서 음원 샘플과 DSP 기준의 최대 차이는 **21.333 ms**로 누적되지 않았습니다. 물리적 마우스·키 입력을 자동 조작한 GUI 검사는 별도로 수행하지 않았습니다.

`Verification/Parade/data-regression.json`은 기존 92개 큐의 기준 시각·발사 기준·상승 시간·발사 위치와 음악 파일이 보존됐음을 확인합니다. 추가 38개 큐의 기준 시각도 모두 실제 음원 분석의 어택 목록에 있습니다. 기존 전체 에셋 백업은 `Verification/BeforeParade/`이며, 이름에 BeforeParade가 붙은 씬·타임라인은 해당 파일 단위의 백업입니다.

아래 음악 분석과 주요 순간의 **시각**은 그대로 유지합니다. 아래 표의 위치·높이·크기는 초기 버전의 기록이며, 현재의 실제 배치와 전체 163개 큐는 현재 타임라인이 기준입니다.

Unity **6000.3.23f1**, 기본 3D 렌더 파이프라인으로 제작했습니다. 사진을 배경 판으로 사용하는 대신 기둥, 들보, 등롱, 기와지붕, 나무, 관객을 3D 오브젝트로 배치했습니다. 불꽃은 월드 공간의 Unity ParticleSystem으로 재생됩니다.

## 열기와 재생

1. Unity Hub에서 이 폴더를 기존 프로젝트로 추가하고 6000.3.23f1로 엽니다.
2. `Assets/Festival/Scenes/LanternFestival.unity`를 엽니다.
3. Game 뷰를 **16:9**로 설정하고 Play를 누릅니다.
4. 3.2초 프리롤 동안 등롱과 밤하늘이 먼저 보입니다. 원본 파일의 0초는 프리롤 뒤입니다.
5. **R**: 음악과 모든 큐를 처음부터 재시작. **Space**: 일시정지/재개. **H**: 간단한 재생 조작 표시.

파일은 189.639833초입니다. 마지막 금빛 꼬리를 위해 파일 종료 뒤에도 최대 9초간 장면이 유지됩니다. 자동 반복은 하지 않습니다.

## 큐 편집

**편집할 원본 데이터:** `Assets/Festival/Data/ShowTimeline.asset`

Inspector의 Cues에서 항목을 펼치면 다음 값을 바꿀 수 있습니다.

| 필드 | 의미 |
|---|---|
| Reference time | 원본 파일 시작 기준 초. 프리롤을 더하지 않습니다. |
| Align to | Burst = 공중 첫 섬광 기준, Launch = 바닥에서 빛이 시작되는 순간 기준 |
| Rise time | 발사부터 공중 첫 섬광까지의 시간 |
| Launch position | 실제 3D 월드 좌표 |
| Height | 발사 위치 위의 폭발 높이. 부채/혜성은 최고 높이이며 0이면 프리팹 기본값 |
| Size multiplier | 크기 |
| Brightness | 큐별 불씨 밝기. 작은 구절에서 크기와 별개로 조절할 수 있습니다. |
| Firework prefab | 사용할 불꽃 프리팹 |
| Deterministic seed | 같은 큐가 재시작해도 같은 모양을 유지하는 난수 시드 |

국화 등 Burst 큐의 **발사 시각 = 기준 시각 − 상승 시간**입니다. 첫 대형 큐의 기준 시각을 66.1813에서 66.0813으로 바꾸면 발사도 63.5813에서 63.4813으로 이동합니다. Inspector에 계산된 발사/첫 섬광 시각이 표시됩니다. 부채와 혜성은 Launch 기준이며 별도의 공중 폭발이 없습니다.

Hierarchy의 `SHOW • select timeline asset to edit cues`를 선택하면 원하는 파일 시각으로 미리 볼 수 있습니다. 편집 모드의 Preview는 무음 정지 미리보기이며, Play 모드에서는 해당 시각부터 음악과 함께 재생합니다. `Clear preview`로 제거할 수 있습니다.

## 프리팹과 구현

`Assets/Festival/Prefabs/`에는 현재 추가 네 종류, 이전 확장 네 종류와 아래 기본 다섯 종류, 총 열세 프리팹이 있습니다.

- `Gold_Chrysanthemum.prefab`: 중심에서 직선에 가까운 구형 방사선, 짧고 선명한 금빛 꼬리.
- `Gold_Willow.prefab`: 더 긴 수명과 중력, 아래로 휘는 금빛 꼬리.
- `Red_ShortBurst.prefab`: 짧은 빨강 방사형.
- `Red_LowFan.prefab`: 바닥에서 솟는 낮은 빨강 부채.
- `Blue_ThinComets.prefab`: 가느다란 파랑 혜성 세 줄. 후반 세 큐에서만 사용.

각 프리팹의 `FireworkEffect`에서 색, 입자 수, 속도, 수명, 중력, 저항, 꼬리 길이와 폭을 바꿀 수 있습니다. 큐 플레이어가 프리팹을 준비하고 재생하므로 프리팹의 ParticleSystem 자체는 자동 방출하지 않습니다. 기본 색은 금색 `#FFD36A`, 빨강 `#E63227`, 파랑 `#548CFF`입니다. 밝은 중심과 가는 꼬리는 별도 파티클 시스템과 재질로 분리했습니다.

`FireworkShowPlayer`는 `AudioSource.PlayScheduled`와 `AudioSettings.dspTime`의 공통 기준점을 사용합니다. 프레임별 대기 시간을 누적하지 않습니다. 입자 위치도 큐 시작 이후의 절대 경과 시각으로 계산하므로 프레임이 밀렸을 때 다음 프레임에서 음악 시각으로 복구됩니다. 시각 출력은 디스플레이 프레임 단위이며 청감상의 출력 지연은 장치에 따라 달라질 수 있습니다.

Unity API 근거: [PlayScheduled](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AudioSource.PlayScheduled.html), [ParticleSystem.Simulate](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/ParticleSystem.Simulate.html).

## 검증과 직접 확인할 지점

검증 결과 파일:

초기 버전의 전곡 검증은 **오류 0건**으로 종료됐습니다. 30/60/90/120/150/180초에 음악 샘플 진행을 확인했고, 134,146회 관측한 음원 샘플 시계와 DSP 기준 시계의 최대 차이는 **0.021333초**였습니다. 이는 출력 버퍼 단위 차이이며 후반으로 누적되지 않았습니다. 250 ms 메인 스레드 지연 후 복구, 다섯 프리팹의 프레임 이력 독립성, 끝 잔광 정리, 재시작, 300 ms 일시정지와 재개도 통과했습니다. 이 값은 디스플레이 지연이나 실제 스피커의 음향 지연을 측정한 값은 아닙니다. 확장판 검증 결과는 `Verification/Parade/`가 기준입니다.

- `Verification/audio-validation.json`: 원본과 출력의 샘플 수·채널·레이트 일치, 시간 이동 없는 정확한 18배 게인, 클리핑 없음.
- `Verification/validation.txt`: 큐 참조, 발사/폭발 관계, 프리롤, 대형 불꽃의 카메라 범위, 메시 유한 좌표 검사.
- `Verification/playback-validation.txt`: 실제 속도의 전곡 Play Mode, 음악 샘플 시계 오차, 250 ms 프레임 지연, 재시작, 일시정지·재개 검사.
- `Verification/01_intro.png`부터 `06_last_accent.png`: Unity Camera로 렌더한 실제 3D 장면. 합성 홍보 이미지가 아닙니다.

Unity 에디터에 완성한 LanternFestival 씬을 열어두었고 씬 로딩 로그와 창 제목으로 확인했습니다. 컴퓨터 사용 도구는 `CreateProcessSecurityEnvironment` 오류로 초기화되지 않아 Inspector를 직접 클릭하는 GUI 검사는 하지 못했습니다. 위 컴파일·렌더·Play Mode 검증은 Unity 자체에서 실행했습니다. 초기 배치 Play Mode 실행 중 Unity Search 인덱스 초기화 예외가 한 번 발생했으나 공연 검증은 정상 완료됐으며, 최종 일반 에디터 실행에서는 해당 예외가 재발하지 않았습니다.

직접 재생할 때에는 **첫 강세 0.57초**, **세 연속 강세 18.91–19.34초**, **끊김과 첫 대형 65–66.18초**, **반복의 높이 변화 67–76초와 155–170초**, **파란 혜성 173.91/177.59/181.14초**, **최종 동시 폭발 188.02초**를 확인하세요. 블루투스 오디오 등의 장치 지연이 있으면 유선 출력으로 먼저 확인하는 편이 타이밍 판단에 도움이 됩니다.
